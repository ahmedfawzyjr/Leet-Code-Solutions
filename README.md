## 📁 Repository Structure

Solutions are categorized into core algorithmic patterns:
- `arrays_strings/`: Two Pointers, Sliding Window, Prefix Sum.
- `linked_lists/`: Fast & Slow Pointers, Reversal techniques.
- `trees_graphs/`: BFS, DFS, Dijkstra, Topological Sort.
- `dynamic_programming/`: Memoization & Tabulation patterns.
